# 🎤 语音输入法 – 专业词库 + 语音宏

> 一款面向专业场景的语音输入工具，支持医学/法律/编程内置词库、用户自定义词库、语音宏快速插入长文本，并具备导入/导出功能。所有数据本地存储，保护隐私。

## ✨ 功能亮点

- **基础语音输入**：开始/暂停/结束录音控制，实时显示临时识别结果，支持清空、一键复制。
- **专业领域词库**：内置医学、法律、编程三套词库（如 `htn` → `高血压`、`array` → `数组`），可随时切换领域。
- **自定义词库**：用户可自由添加缩写 → 术语映射（如 `ai` → `人工智能`），优先级高于内置词库。
- **语音宏**：说一句“运行宏问候语”即可插入预设长文本，支持用户自定义宏（增删改查），自动保存。
- **导入/导出**：所有宏和自定义词库可导出为 JSON 文件，也可导入备份，方便分享与迁移。
- **隐私安全**：词库和宏完全存储在浏览器本地（localStorage），不上传任何服务器。

## 💡 设计初衷

通用语音输入法在专业场景（医生、程序员、客服）下效率不高——术语识别率低、重复文本输入慢。本作品通过**专业词库**和**语音宏**精准解决这两个痛点，且所有数据本地存储，保护隐私。

## 🛠 技术栈

- HTML5 / CSS3 / JavaScript (原生，无框架)
- Web Speech API（语音识别，基于浏览器内置引擎）
- localStorage（数据持久化）
- Clipboard API（复制功能）

## 🌐 浏览器兼容性

本项目基于 Web Speech API 实现语音识别，推荐使用以下浏览器以获得最佳体验：

- ✅ **Google Chrome**（版本 90+，完全支持）
- ✅ **Microsoft Edge**（版本 90+，完全支持）
- ⚠️ **Safari**（部分支持，可能需要 HTTPS 环境）
- ❌ **Firefox** 桌面版（默认关闭，需手动开启 `media.webspeech.recognition.enable` 标志）
- ❌ **其他浏览器**（如 Opera、IE 等不支持）

> 如果您使用的是移动端，Chrome for Android 和 Safari on iOS 均可使用（iOS 需 HTTPS 环境）。

## 💡 使用小贴士

- 首次使用请允许麦克风权限。
- 录音时建议在安静环境下，清晰发音。
- 宏触发词支持：`宏`、`插入宏`、`运行宏`、`使用宏`、`调用宏`，例如说“运行宏问候语”。
- 若识别出的宏名称包含标点，系统会自动清理，无需担心。
- 自定义词库和宏均支持增删改查，关闭页面后不会丢失。
